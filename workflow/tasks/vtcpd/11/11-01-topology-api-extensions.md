# 11-01 - Topology API Extensions

# Links
- [PRD](../../prd/vtcpd/11-path-rebuilding-on-inaccessible-nodes.md)

# Description
Розширити `TopologyTrustLinesManager` та `EquivalentsSubsystemsRouter`, щоб координатор міг вилучати ребра топології та перераховувати відомих учасників перед перебудовою шляхів. Це забезпечує передумови для виключення недоступних нод і відхилених ліній довіри згідно з PRD (розділ "Topology Manager / Router API: розширення для модифікації топології").

# Requirements and DOD

## Functional Requirements
1. Додати публічний метод `void removeTrustLine(ContractorID sourceID, ContractorID targetID)` у `TopologyTrustLinesManager`, який безпечно видаляє ребро та оновлює внутрішні структури (`msTrustLines`, таймери / сеттерів).
2. Переконатися, що при видаленні останнього ребра для вузла структура очищається без витоків та залишкових покажчиків.
3. Додати публічний метод `std::vector<ContractorID> participantsIDs() const` (або аналогічний контейнер) у `EquivalentsSubsystemsRouter`, що повертає унікальні вже зареєстровані ContractorID без побічних ефектів.
4. Оновити заголовки та реалізації, забезпечити включення необхідних хедерів і дотримання існуючого стилю журналювання.

## Definition of Done
- [ ] Нові методи додані до відповідних заголовків і реалізацій.
- [ ] `removeTrustLine` успішно видаляє ребро й очищає структури при юніт-тесті.
- [ ] `participantsIDs()` повертає повний набір ContractorID у порядку додавання без дублювання.
- [ ] Існуючі компіляційні цілі збираються без помилок.
- [ ] Додані мінімальні юніт-тести, що покривають обидва нових методи.

# Implementation Plan
1. **TopologyTrustLinesManager** (`src/core/topology/manager/TopologyTrustLinesManager.{h,cpp}`)
   - Оголосити метод `removeTrustLine` поруч із `addTrustLine`.
   - Реалізувати видалення з `msTrustLines` та пов’язаних контейнерів; видаляти `TopologyTrustLineWithPtr`, якщо він більше не використовується.
   - Логувати кількість вилучених ребер для налагодження.
2. **EquivalentsSubsystemsRouter** (`src/core/equivalents/EquivalentsSubsystemsRouter.{h,cpp}`)
   - Додати новий метод, що ітерує `mParticipantsAddresses`, повертаючи масив ContractorID.
   - Забезпечити відсутність зміни стану й дотримання const-коректності.
3. **CMake / включення**
   - Перевірити, що нові методи не вимагають додаткових залежностей; за потреби оновити include.
4. **Тести**
   - Створити/оновити модульні тести (наприклад, у `tests/unit/topology/TopologyTrustLinesManagerTests.cpp` або аналогічному) для перевірки обох методів.

# Test Plan
- **Unit Tests (Moderate)**:
  - Перевірити, що `removeTrustLine` прибирає ребро та очищає контейнер при повторному виклику.
  - Переконатися, що видалення останнього ребра видаляє порожній набір і не викликає помилки.
  - Перевірити, що `participantsIDs()` повертає всі очікувані ContractorID у порядку реєстрації без дублювань.
- **Static Analysis**: переконатися, що інструменти (якщо підключені) не сигналять про витоки.

# Verification and Validation

## Reliability

## Compliance
